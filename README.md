# AI Chatbot using Python 🤖

A simple AI chatbot developed using Python that provides automated responses to user queries. The chatbot uses predefined conversation patterns to understand user input and generate relevant replies.

## Features
- Interactive text-based conversation
- Automated response generation
- Handles multiple user queries
- Simple and beginner-friendly implementation

## Technologies Used
- Python

## Skills Demonstrated
- Python Programming
- Basic AI Concepts
- Chatbot Development
- Problem Solving

## How It Works

1. The user enters a message through the chatbot interface.
2. The chatbot converts the input into lowercase text for processing.
3. It checks the user's message against predefined keywords.
4. If a matching keyword is found, the chatbot selects a suitable response.
5. If no match is found, the chatbot returns a default message.
6. The conversation continues until the user types "bye".
